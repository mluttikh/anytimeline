# Tutorials

Lessons that take you through anytimeline step by step. Do them in order; each takes about
ten minutes.

1. [Your first event chart](first-chart.md): draw a log of events on lanes, color them, and
   look around in the plot.
2. [Follow the order of events](order.md): switch to the Order scale, join each request's
   events into a route, and read where time went.
3. [Select events and use them in Python](select.md): pick events in the plot and get their
   rows back.
